# 🐳 FraudShield — Single Container

A single Docker container serving a trained XGBoost fraud detection model via FastAPI REST API.

---

## 🎯 What This Does

Trains an XGBoost model on credit card transaction data and serves it as a containerized REST API. The model uses SMOTE to handle class imbalance and achieves AUC of 0.9947.

---

## 🗂️ Files

```
docker-basics/
├── train.py          → Trains XGBoost model, saves artifacts
├── app.py            → FastAPI prediction service
├── Dockerfile        → Container definition
├── requirements.txt  → Python dependencies
└── README.md
```

> **Note:** `model.pkl`, `scaler.pkl`, `metrics.json`, `category_map.json` are generated by `train.py` and not committed to GitHub.

---

## 🔬 Model Details

| Attribute | Value |
|-----------|-------|
| Algorithm | XGBoost Classifier |
| Imbalance | SMOTE oversampling |
| AUC | 0.9947 |
| Precision | 0.8673 |
| Recall | 0.8522 |
| F1 Score | 0.8596 |

**Features used:**
`amt`, `hour`, `day_of_week`, `month`, `distance`, `age`, `gender_enc`, `category_enc`, `city_pop`, `zip`

## 🚀 How to Run

### Step 1 — Download Dataset
Download from Kaggle:
👉 https://www.kaggle.com/datasets/priyamchoksi/credit-card-transactions-dataset

Place CSV in `../data/creditcard_sample.csv`

### Step 2 — Train Model
```bash
pip install -r requirements.txt
python train.py
```

Expected output:
```
✅ Loaded 58,694 records | Fraud: 0.98%
✅ After SMOTE: 46,495 legit | 46,495 fraud
📊 roc_auc: 0.9947
✅ Saved: model.pkl | scaler.pkl | metrics.json | category_map.json
🎉 Training complete!
```

### Step 3 — Build Docker Image
```bash
docker build -t fraudshield-api:v1 .
```

### Step 4 — Run Container
```bash
docker run -d -p 8000:8000 --name fraudshield-api fraudshield-api:v1
```

### Step 5 — Verify
```bash
# Check container running
docker ps

# Health check
curl http://localhost:8000/health
```
